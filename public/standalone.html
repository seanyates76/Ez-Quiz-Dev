EZ QUIZ · STANDALONE PREVIEW

A study space
you can keep.

EZ Quiz began as a small way to turn curiosity into practice. This edition keeps that idea available as an app you can run yourself. No EZ Quiz account, hosted AI relay, or shared API bill.

Start on your computer

  1. Install Node.js 22 or newer.
  2. Download the source ZIP from the public repository and extract it. Use a version that includes the standalone folder. Development previews are in Ez-Quiz-Dev.
  3. Open a terminal in that folder and run:
npm start

No npm install or Netlify account is needed to run this edition. Open http://127.0.0.1:8787 and keep the terminal open. Press Ctrl+C to stop. Windows, macOS, and Linux use the same command.

This is a local browser app with a small Node launcher. It is not a native desktop installer. The launcher accepts connections only from your own computer; it is not a LAN or public web server.

Try it before connecting AI

Choose Try a demo, then Start Quiz. Or choose Write a quiz to use the interactive or manual editor. Open .txt loads a saved quiz. Save .txt exports a portable copy that you can keep or share yourself.

Bring your own key

  1. Open Settings → Your AI connection.
  2. Choose Gemini or OpenAI and paste a key created in that provider’s console.
  3. Choose Save settings. Your key is remembered on this device. Uncheck Remember key to use it for this visit only.
  4. Optionally choose Load models to check access and list model IDs. Select a text-capable model, then save.
  5. Enter a topic or attach study material and choose Create Quiz. Review or edit, then start.

Gemini keys · OpenAI keys. Provider access, availability, billing, and data retention belong to your provider account. A ChatGPT subscription does not supply an OpenAI API balance.

Generation uses small batches with bounded attempts to fill a short result. Each AI request can cost money. Stopping aborts the current local request and prevents further batches; already processed provider work may still be billed. Completed questions remain usable.

What works where

FeatureNeeds
Demo, manual quiz import/editing, scoring, retakes, exportBrowser; works offline after the app shell is cached
TXT, Markdown, HTML, CSV, JSON, RTF study materialBrowser; text is read locally
DOCX study materialLocal launcher; no AI key or internet
AI generation and answer explanationsLocal launcher, internet, provider key and compatible model
PDF study materialGemini; confirmation before the file is sent
PNG, JPEG, GIF study materialGemini or a compatible OpenAI vision model; confirmation before sending

Binary imports have a 4 MiB limit. Extracted source text is limited to 60,000 characters. Review extraction quality, especially scanned PDFs, tables, and RTF formatting. Unsupported or empty files are reported rather than silently sent somewhere else.

Your work stays portable

The latest quiz and preferences are saved in your browser profile. In-progress answers and explanations are temporary. Export important quizzes; browser storage is not a backup. Use the same local address and port to return to the same saved settings.

If something does not work

  • Model unavailable: Load models and choose another compatible model ID.
  • Quota or rejected key: check the provider console and API permissions.
  • Port busy: stop another running copy or set EZQ_PORT to a different port.
  • Old interface: refresh when your quiz is finished. Export first before using Reset App.
  • Double-clicking index.html fails: use the launcher; JavaScript modules require an HTTP origin.
