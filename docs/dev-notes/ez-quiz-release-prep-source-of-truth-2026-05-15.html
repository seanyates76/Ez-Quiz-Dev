Current Product Framing

EZ Quiz is now framed around reliable study practice: provide a topic or focused study material, create a valid quiz, start when ready, then review results with explanations.

This version is meaningfully better than the current live site because it separates building from taking, avoids over-promising large generation, and presents the first-use intro cleanly.

Core promise: Create builds. Start begins. Results explain.

Public Quiz Limits

  • Public quiz length is capped at 20 questions.
  • Visible options are 5, 10, 15, and 20.
  • Do not advertise 30/50 as available public options yet.
  • 30/50 remains a future reliability goal tied to staged/async generation.

Current Stable App Flow

Create Quiz Topic or study material starts the build.
Status Build state explains readiness or failure.
Start Quiz Enabled only after a valid quiz exists.
Results Completed quiz moves into review mode.
Explanations Missed concepts can be reviewed on demand.

What Works Now

  • Start Quiz stays disabled until a valid quiz exists.
  • Failed creation does not erase the last valid quiz.
  • Live Gemini generation passed for 5, 10, and 20 questions after increasing provider output budget.
  • Explainers work.
  • Media ingest works.

Intro Panel State

Known User Guidance

Use concise, trust-preserving copy around generation reliability.

For best results, paste a focused section of notes, a lesson, or a short study guide. Full course notes may work better when split into smaller chunks.
