Morning Verdict

EZ Quiz is closer to final form. The app now treats imported material as source first, extracts deterministic text before spending AI tokens, gives larger note-style files room to breathe, and presents the quiz results endpoint with a cleaner finish.

The branch is locally verified and committed. The main promotion caveats are operational: normal netlify dev can still be misleading because team-level Netlify AI Gateway values can shadow direct provider keys, and larger 30/50-question generation still needs reliability hardening before it becomes a public option.

Import Model

Support is no longer PDF/image only. Text-like files are extracted locally or deterministically first, then normalized and capped before the model sees them.

  • .txt, .md, .html, .csv, .json, and .rtf are handled as text source.
  • .docx is extracted server-side from Word document XML.
  • PDFs and images still use provider-backed extraction when deterministic text is not practical.

Generation Model

Public quiz creation now stays within 5, 10, 15, and 20-question lengths, with explicit failure copy instead of silently hanging. Larger 30/50-question creation remains future reliability work.

  • Default large-request batch size is smaller.
  • Under-count and timeout copy is more honest.
  • Async jobs with progress remain the durable path.

UX Finish

The pass focused on product behavior first, then made the final result screen feel less provisional.

  • "Start New" became "New Quiz".
  • The landing information panel no longer looks like fake window chrome.
  • Correctness pills now sit in the top-right corner of result cards.
  • The results header has a more deliberate final-stop layout.

Limits Answer

Yes, there still needs to be a limit. Extracting text first means the model does not pay for raw file bytes, but the app still has browser memory, request payload, parsing time, provider context, abuse, and cost ceilings.

That is why text-ish files can be larger locally, while direct binary uploads remain smaller until the product has a blob-backed or async import flow.

Model Answer

Other models remain on the table only if they fit the free-tier constraint. No provider swap was made in this pass because the immediate reliability wins were batching, deterministic extraction, and better runtime clarity.

Before adding another provider, the better next test is a clean live smoke through the intended Netlify path with AI Gateway either disabled or intentionally integrated.

Recommended Next Move

Run Intentional Provider Smoke

Use netlify dev --offline for direct-provider smoke, or disable/integrate Netlify AI Gateway before trusting normal netlify dev. Verify generation, lazy explanations, and import in the same runtime path.

Decide On Async Investment

If larger 30/50-question quizzes and large binary documents become core product promises, move generation and binary import to async jobs with progress, retry, and resumable state.

Redesign Source Modes

Split the first screen into explicit choices: short topic prompt, pasted notes/source material, imported document source, and manual quiz lines. This is the highest-value UX cleanup still waiting.

Promotion Review

With the branch clean and tests green, promotion readiness now depends on live runtime smoke and keeping larger 30/50-question generation out of the current public update.
