EZ Quiz Quality-First UX Understandability Pass

Internal planning brief for moving the first-use experience toward a simple study flow: topic or study material in, high-quality quiz out, take quiz, review missed answers with explanations.

Created May 15, 2026 Scope: understandability Keep parser support advanced

Product Goal

A stranger should understand what to do in a few seconds.

EZ Quiz should present two beginner-friendly starting points: a short topic, or study material such as pasted notes and imported files. Manual formatted quiz lines should remain available, but they should not define the product for new users.

Current Friction Points

  • Topic input, file import, pasted notes, and formatted quiz lines compete for attention.
  • The landing page gives "Paste quiz lines" equal weight with topic and import actions.
  • "Topic or title" does not clearly mean "short topic only."
  • Study-material import is powerful, but the first screen does not explain when to use it.
  • Manual format help introduces MC/TF/YN/MT syntax too early.
  • Some main-page copy uses implementation terms like "batch-backed" and "Lazy."
  • Help content spends too much early space on Editor, Mirror, and raw-line behavior.

What Already Works

  • The app already supports the desired learning loop: generate, take quiz, review results.
  • Imported source text is already kept separate from the topic label in the generation payload.
  • Supported import types now cover common study-material formats.
  • Advanced editor/manual parsing is already collapsible under Options.
  • Results explanations are user-facing as simple "Explanation" blocks, which fits review mode.
  • The current visual direction is restrained and practical enough to keep.

First-Use Experience Target

Start Landing page

Open with a clear promise and one question: what are you starting with?

Choose Topic or material

Let users pick a short topic or study material without seeing manual syntax.

Provide Input

Show an input panel that clearly matches the chosen path.

Create Generate quiz

Generate a quiz with count, difficulty, and type controls kept secondary.

Practice Take quiz

Run the quiz without exposing raw quiz-line internals.

Review Results

Review missed answers with simple explanations and retake options.

Recommended Improvements For Today

Primary

Make the first choice explicit

Replace equal hero actions with a clear "What are you starting with?" choice. The two beginner paths should be A topic and Study material.

Primary

Match the panel to the path

Topic mode should show a short one-line input. Study-material mode should support pasted notes and an attach/import action with plain-language helper text.

Demote manual formatted lines

Move "Paste EZ Quiz formatted lines" to Advanced / Manual import. It should be discoverable for returning users, not centered for beginners.

Remove implementation language

Replace wording such as "Lazy," "batch-backed," "parser," "schema," and "raw lines" from main first-use copy.

Advanced / Manual Functionality

Where it should live: under Options, inside a renamed disclosure such as Advanced / Manual import or Manual quiz import.

How to describe it: "Already have EZ Quiz formatted lines? Paste them here to start or edit a quiz."

  • Keep the exact format reference inside this advanced area.
  • Keep parser support and import of saved quiz text.
  • Do not use parser syntax in hero copy, primary cards, or beginner help.
  • Use "manual format" or "formatted lines" in advanced UI; avoid "parser" for users.

Later / Future Improvements

  • Async generation jobs for reliable large quizzes.
  • Progress UI for multi-step generation, validation, and repair.
  • Larger binary import via blob-backed or resumable upload flow.
  • Better source state management when starting a new quiz.
  • Preference-backed "do not show again" behavior for any informational panels.
  • Full editor IA cleanup after the first-use path is clear.

Quality-Generation Roadmap

Blueprint

Build a coverage plan from the topic or source material before writing questions.

Smaller Batches

Generate focused groups of questions instead of asking for all 30 to 50 questions at once.

Concept Tracking

Track what concepts have already been covered so later batches fill gaps instead of repeating.

Dedupe And Validation

Check for repeated stems, invalid answers, weak options, missing matches, and unsupported formats.

Repair Weak Questions

Repair or replace questions that are repetitive, too vague, too easy for the requested difficulty, or not grounded in the source.

Final Assembled Quiz

Assemble the final set only after coverage, quality, count, and answer validity are confirmed.
